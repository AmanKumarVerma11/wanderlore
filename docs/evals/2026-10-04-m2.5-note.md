# Milestone 2.5 follow-up eval: a note that shapes the plan

Run on 2026-10-04 with
`GEMINI_MODEL=gemini-3.5-flash-lite NVIDIA_API_KEY= npm run eval -- --name 2026-10-04-m2.5-note`
on the working tree as handed over (not yet committed). Same settings as
`2026-10-03-m2.5.md`, with two new cases (26 in all) and a new grader.

New since the M2.5 run:
- **The note.** The prompt quotes it as the traveller's own words and asks for it
  in the places, experiences and tips. A `noteFit` field, second in the schema,
  tells the traveller how the plan follows it.
- **Two note cases.** `himachal-3-treks-note` is the request that prompted this
  change ("off beat treks"); `kyoto-2-toddler-note` is a short note
  ("travelling with a toddler"). `mexico-city-long-note` is tagged as a note
  case too.
- **A grader, `note_reflected`.** Each note case lists what the note asks for, as
  patterns. The grader looks for them only in the places, experiences and tips:
  a day theme, the story or `noteFit` that names the note doesn't count.

## Before and after, on the note cases

Two runs of the three note cases with the old prompt, then two with the new one,
same model (`--tag note`). "Mentions" counts matches of the note's patterns in the
places, experiences and tips.

Mountain Paths", "Offbeat Trails in Bir") while their places stayed temples,
monasteries and restaurants. The first version of `note_reflected` read the whole
plan and passed both; it now ignores themes.
