# Milestone 1 eval: the new pipeline

Run on 2026-10-03 with `npm run eval -- --name 2026-10-03-m1` on the milestone 1
working tree (not yet committed). Model: `gemini-3.5-flash-lite` as primary
(`GEMINI_MODEL`), with `gemini-3.1-flash-lite` as fallback: the same primary model
as the baseline run in `2026-10-03-baseline.md`, so the 12 core cases compare the
pipelines alone. The NVIDIA key was still set locally; both endpoints answered 410,
so every case took the single-Gemini path, as in the baseline.

All 24 cases ran: 12 core, 6 hard (ambiguous and informal names, small places),
4 limits (7-day packed, long note, prompt-injection note, single day) and 2
gibberish destinations that must be rejected before any model call.
