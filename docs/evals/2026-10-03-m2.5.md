# Milestone 2.5 eval: phrases you can hear

Run on the night of 2026-10-03 with
`GEMINI_MODEL=gemini-3.5-flash-lite NVIDIA_API_KEY= npm run eval -- --name 2026-10-03-m2.5`
on the milestone 2.5 working tree as handed over (not yet committed). Same settings
as the M2 run in `2026-10-03-m2.md`: `gemini-3.5-flash-lite` writes the plan, with
`gemini-3.1-flash-lite` as fallback, and the NVIDIA panel off.

New in milestone 2.5:
- **Phrase fields.** Each phrase now carries a BCP 47 language tag and a
  pronunciation guide, both required by the response schema.
- **A grader, `phrase_script`.** It fails a plan if any phrase is mostly outside
  the script its language tag implies, or has an invalid tag. The page uses the
  same check (`inOwnScript` in `lib/speech.ts`) to decide whether to offer audio.

## How this run came about

This is the second full M2.5 run.

1. **Before the script check** (all 24 cases). Every grader of the time passed
   except `place_budget` on nyc-informal: 4, 4 and 3 stops where 4 to 5 were
   asked. Reading the new fields found 7 of 97 phrases, in 4 of 22 plans, that a
   voice would misread: "Har Har Mahadev" in Latin letters tagged as Hindi,
   Kannada written in Latin letters, and "खamma ghani", which switches script
   mid-phrase. Re-graded offline with `phrase_script`, those 4 plans fail.
2. **Two 4-case reruns** of those destinations, with two rewordings of the
   prompt, still had off-script phrases in 2 and then 4 of the plans.
3. **This run** keeps the second wording ("never romanized") and adds the page
   guard: audio only for phrases in their own script.

## Which number to read

`phrase_script` failed in the same 4 plans before and after the rewording (7
phrases before, 8 after), so the wording made no measurable difference. What
protects the feature is the page guard: none of these phrases gets a *Listen*
button, and their written guides still show.

Each run plans different places, so grounding totals move between runs. The
paired number is "Found by repair": places the first pass missed and repair
found, in the same plans.
